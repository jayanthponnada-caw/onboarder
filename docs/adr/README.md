# Architecture Decision Records

This directory contains ADRs for Onboarder.

Create an ADR only when the decision is all three:

- Hard to reverse.
- Surprising without context.
- The result of a real trade-off.

Use sequential filenames:

```txt
0001-short-decision-title.md
0002-next-decision-title.md
```

Keep each ADR short:

```md
# Short title

One to three sentences describing the context, the decision, and why it was chosen.
```

Use root `CONTEXT.md` for project language. Use ADRs for durable architecture decisions, not implementation notes or scratch planning.
